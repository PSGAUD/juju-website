# Juju — a little digital gift

This is a fully static website: open `index.html` in a browser, or use the VS Code Live Server extension for a local preview. No installation or backend is needed.

## Personalize it

- **Photos:** replace `images/photo1.webp` through `images/photo6.webp` with your own files, keeping the same filenames. Update the titles, captions, and photo paths in `index.html` where the comments say `CHANGE`.
- **Letter:** find `EDIT YOUR FULL LETTER BELOW` in `index.html` and replace the text inside `.letter-text`.
- **Memories:** search `index.html` for `[ADD` to find every personal placeholder quickly.
- **Music:** put an MP3 called `song.mp3` in `music/`. The music button only plays it after a visitor taps it.

## Deploy

Upload this folder to any static host. For GitHub Pages, create a repository, upload all files and folders, then in **Settings → Pages** choose the `main` branch and `/ (root)` folder. The page will be published at the URL GitHub gives you.

The included images are local placeholder assets only. Replace them with your real memories before sharing.
